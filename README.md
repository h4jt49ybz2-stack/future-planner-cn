# 向前 · 生涯路径规划

一个帮助学生整理个人背景、比较就业与升学路径、规划下一步行动的中文静态网页。

## 功能

- 汇总教育背景、实习与项目经历、技能和证书
- 对照个人意愿、家庭期待和现实约束，比较就业、升学、探索等方向
- 导入或手动维护岗位信息，并核对学历、毕业时间、资格和招聘要求
- 将规划与任务保存在当前浏览器，支持打印和导出为 PDF

## 本地运行

页面没有构建步骤和第三方依赖。用浏览器打开 `dist/index.html` 即可；也可以将 `dist/` 部署到任意静态网站托管服务。

## 数据与隐私

个人资料、岗位清单和任务保存在浏览器的 `localStorage` 中。导入的 CSV 在浏览器本地读取。请勿在共享设备上填写不希望他人看到的信息；清除浏览器网站数据会删除本地保存内容。

## 注意事项

岗位筛选信息需要以招聘单位的官方招聘页面为准。路径评分用于帮助整理思路，不构成就业、升学或法律建议，也不会保证录取或录用结果。
